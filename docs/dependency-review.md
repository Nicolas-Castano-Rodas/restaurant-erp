# Dependency candidate (isolated branch)

This branch is a reproducible experiment, not a release. The CI resolves Prisma CLI, client and PostgreSQL adapter 7.10.1 together and tries an ExcelJS-scoped uuid 11.1.1 override. Versions are hypotheses based on the audit of e7d786d, not verified fixes. The resolver generates manifests only inside the runner; both are uploaded as dependency-candidate. No dependency files on main are changed and no write permissions are granted to the runner. If resolution, installation, integration, exports, browser, container and audit pass, review the generated manifests and merge them with normal CI on main. If any check fails, inspect logs and adjust the candidate rather than forcing upgrades. Moderate findings still require review even when the high-severity gate passes. Do not merge this experimental workflow over main.

## Segunda revisión
La primera ejecución (45689395464) superó todas las pruebas funcionales, Chromium, Docker y restauración. El informe completo bajó de 7 hallazgos a 3 altos, asociados a effect <=3.22.0 y sus dependientes @prisma/config y prisma. Se añade un override limitado al consumidor @prisma/config de effect ^3.22.1, condicionado a que exista una versión compatible publicada en npm. No se cambia la versión de Prisma ya probada ni se baja a Prisma 6. La auditoría completa conserva el umbral alto y el candidato sigue aislado. Si no se resuelve o falla la generación, migraciones, reportes u otras pruebas, no integrar. Tras una ejecución exitosa, comprobar el árbol de dependencias y usar los manifiestos exactos del artefacto para una nueva validación en main.
